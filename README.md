# X-Plane 12용 한국 시너리 저장소

## DINKIssTyle_KOREA_Buildings_*
지역별 건물 시너리입니다.

DINKIssTyle_KOREA_Buildings_* 이름 구조에서 예외인 폴더

- DINKIssTyle_KOREA_Buildings_00_TOP
  - DINKIssTyle_KOREA_Buildings 를 보정하는 최상위 시너리입니다.
- DINKIssTyle_KOREA_Buildings_93_Forest_1
- DINKIssTyle_KOREA_Buildings_94_Forest_2
  - 한반도 숲을 표현하는 시너리입니다.
- DINKIssTyle_KOREA_Buildings_99_INT
  - DINKIssTyle_KOREA_Buildings_* 시너리가 올바르게 작동하기 위한 라이브러리 입니다.

 ### 수정 사항 반영을 위해서
